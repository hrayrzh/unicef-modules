# UNICEF Armenia — Образовательные модули для родителей

Проект: серия из **5 обучающих модулей** для родителей и опекунов о цифровой безопасности детей.
Сейчас в работе: **Модуль 1 — «Ծնողական վերահսկողություն» (Родительский контроль)**.

Текущий этап: **выбор дизайн-концепции**. Делаем 4 разных прототипа одного и того же модуля,
показываем стейкхолдерам, получаем отзыв, выбираем один — он станет основой для всех 5 модулей.

**Правило:** контент живёт только в `shared/module-01.js`. Ни один концепт не хардкодит
текст модуля у себя. Правка формулировки = правка в одном месте, обновляются все 4.

Пути относительные (`../../shared/module-01.js`) — работает и по `file://`, и на GitHub Pages.

### Разметка внутри текстов контента

В строках контента используется своя мини-разметка, чтобы каждый концепт мог подать
одно и то же по-своему:

| Маркер | Значение | Пример |
|--------|----------|--------|
| `[[English\|Русский]]` | Название настройки: оригинал + рус. эквивалент | `[[Screen Time\|Экранное время]]` |
| `**жирный**` | Смысловой акцент | |
| `{{n}}` | Ссылка на источник №n из `MODULE_01.sources` | `{{1}}` |

Каждый концепт реализует свою функцию `render(text)`:
- A — `Screen Time (рус. «Экранное время»)`, как в оригинале
- B — армянский текст, рус. подсказка по тапу
- C — моно-чип `Screen Time` + тултип
- D — только оригинал, рус. мелко под абзацем

## 3. Механика прохождения (D9) — общая для всех концептов

Модуль нельзя пролистать. Каждая страница открывает следующую только после **доказанного действия**.
Реализация различается по концептам, но набор проверок общий:

| Тип гейта | Что требуется | Зачем |
|-----------|---------------|-------|
| `read` | Долистать до конца страницы — маркер внизу должен попасть во вьюпорт | Нельзя нажать «Далее» не увидев текст |
| `expand` | Раскрыть все свёрнутые блоки на странице | Заставляет открыть каждый гайд, а не проскочить раздел |
| `check` | Отметить все пункты. **Чекбокс заблокирован, пока соответствующий блок не раскрыт** | Убивает сценарий «отметить всё автоматом» |
| `quiz` | Ответить правильно на контрольный вопрос | Проверка понимания, а не присутствия |

**Ключевое анти-чит правило:** отметка «выполнено» физически недоступна до раскрытия инструкции.
Порядок всегда: раскрыл → прочитал → отметил → открылась кнопка «Далее».

У гайдов две допустимые отметки — `Կատարված է` (сделано) и `Չի վերաբերում` (не применимо).
Вторая нужна честно: не у каждой семьи есть PlayStation. Но выбрать её тоже можно только раскрыв гайд.

Кнопка «Далее» в заблокированном состоянии **всегда объясняет причину** («Մնաց 3 կետ», а не просто серая кнопка).
Пройденные шаги остаются доступны для возврата; непройденные — заблокированы, с иконкой замка.

Прогресс хранится в `localStorage`. При недоступном хранилище (iframe с жёсткими правилами)
модуль работает, но прогресс не переживает перезагрузку — это осознанный компромисс до появления бэкенда.

## 4. Четыре концепта

Все четыре подчиняются D9. Различаются тем, **чем именно доказывается прохождение**.

### A — «Ուղեցույց» / Справочник · строго UNICEF
- **Визуал:** UNICEF cyan `#1CABE2`, белый, тёмно-синий текст, Noto Sans Armenian. Официально, чисто, доверительно.
- **Структурный приём:** армянские буквы Ա Բ Գ Դ Ե как якоря разделов — взяты прямо из исходного документа.
- **Логика:** 12 страниц. Дочитал → раскрыл все гайды → отметил каждый → контрольный вопрос → следующая.
- **Доказательство прохождения:** раскрытие + отметка по каждому гайду + один контрольный вопрос на страницу.
- **Кому зайдёт:** тем, кто хочет строгий официальный материал, который не стыдно показать донорам.

### B — «Ուղևորություն» / Путь · UNICEF-основа + вариация
- **Визуал:** UNICEF cyan + глубокий синий + тёплый коралловый акцент. Noto Serif Armenian в заголовках, Space Grotesk для чисел.
- **Структурный приём:** вертикальная маршрутная нить вместо полосы прогресса — видно, где ты и что впереди закрыто.
- **Логика:** остановки маршрута. Каждая — один экран, без длинной прокрутки.
- **Доказательство прохождения:** обязательный микро-вопрос на каждой остановке + выбор, который записывается в личный план.
- **Финал:** «Ձեր ընտանեկան պլանը» — персональный чеклист, собранный из ответов, готовый к печати.
- **Кому зайдёт:** тем, кому важна измеримая завершённость и ощущение курса.

### C — «Վահան» / Щит · собственный визуальный язык
- **Визуал:** тёмная сине-графитовая панель, янтарный и бирюзовый акценты, моноширинный шрифт для названий настроек. Инструмент, а не статья. Тёмная тема оправдана сценарием: родитель настраивает вечером, когда дети легли.
- **Структурный приём:** сначала собираешь свой дом из карточек устройств — дальше модуль показывает только твои гайды.
- **Логика:** страницы = разделы твоего набора. Пустые разделы пропускаются.
- **Доказательство прохождения:** каждый шаг гайда отмечается отдельно, не гайд целиком. Индикатор `Ձեր պաշտպանվածությունը: 62%`. Вместо теста — стресс-тест из 5 жизненных сценариев.
- **Кому зайдёт:** тем, кто ценит «сел и сделал прямо сейчас».

### D — «Զրույց» / Разговор · собственный визуальный язык
- **Визуал:** светлый холодно-белый фон, глубокий сливовый чернильный текст, фиолетовый и тиловый акценты. Крупный гротеск с широкими интерлиньяжами, без серифов. Сознательно уходит от «кремовой бумаги с терракотой».
- **Структурный приём:** возрастной слайдер 5 → 17 лет. Двигаешь — риски, фокус и инструменты перестраиваются под возраст твоего ребёнка.
- **Логика:** страницы-развороты. Чтобы открыть следующую, нужно применить слайдер к своему случаю.
- **Доказательство прохождения:** рефлексия «Ի՞նչ կասեիք» — выбираешь реплику родителя, получаешь разбор. Не тест на память, а тренировка реакции.
- **Кому зайдёт:** тем, для кого главное сообщение модуля — доверие, а не контроль.

## 5. Технические правила

- Никакой сборки, никаких зависимостей кроме Google Fonts. Открывается двойным кликом.
- Шрифты: `Noto Sans Armenian` / `Noto Serif Armenian` для армянского. Латиница — свой акцентный шрифт в каждом концепте. Обязательный системный fallback: `Mshtakan, Sylfaen, system-ui`.
- Прогресс/отметки — `localStorage`, ключ `unicef-m01-<concept>`. В iframe может быть заблокирован → оборачивать в `try/catch`, приложение должно работать и без него.
- Уважать `prefers-reduced-motion`: все анимации отключаются.
- Доступность: контраст не ниже AA, семантические заголовки, фокус виден, квиз проходится с клавиатуры.
- Никаких внешних картинок — только inline SVG и CSS. Материал должен работать офлайн и внутри iframe с жёстким CSP.
- Не использовать фиксированную высоту `100vh` для основного контейнера — сломается в iframe.

## 7. Структура контента Модуля 1 (каркас для всех 5 модулей)

Этот скелет повторяется в каждом модуле — на нём строится компонентная система:

1. **Обложка** — номер, заголовок, подзаголовок, дисклеймер
2. **Главный вопрос** — врезка, задающая проблему
3. **Цель** и **Целевая группа**
4. **Как пользоваться** — врезка-инструкция
5. **Теория** — таблица возрастных стадий, вызовы среды
6. **Практика** — пошаговые гайды, сгруппированные (ОС / соцсети / игры / мессенджеры)
7. **Чеклист** — сквозная последовательность действий
8. **Мягкая часть** — исследования, скрипты «что сказать / что не сказать», принципы
9. **Золотое правило** — ключевая врезка
10. **Экстренная помощь** — контакты
11. **Доп. материалы** — hy / ru
12. **Источники** — нумерованный список со ссылками
13. **Квиз** — формат зависит от выбранного концепта

Повторяющиеся типы блоков: `⚠ предупреждение`, `🔑 золотое правило`, `✓/✕ скрипты диалога`,
`пошаговый гайд`, `сравнительная таблица`, `чеклист`, `карточка контакта`.
