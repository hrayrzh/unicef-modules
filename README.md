# UNICEF Armenia — Модуль 1: четыре концепции

Прототипы обучающего модуля «Ծնողական վերահսկողություն» для родителей.
Четыре варианта дизайна и логики обучения — для выбора одного направления,
на котором будут построены все 5 модулей.

**Витрина:** `index.html` — сравнение четырёх вариантов.

| | Вариант | Логика |
|---|---------|--------|
| A | Ուղեցույց · Справочник | Строгий бренд UNICEF, 13 страниц, финальный тест |
| B | Ուղևորություն · Путь | Маршрут с остановками, микро-вопросы, личный план |
| C | Վահան · Щит | Тёмная панель-инструмент, набор под свои устройства, стресс-тест |
| D | Զրույց · Разговор | Возрастной слайдер, рефлексия «что бы вы сказали» |

Во всех четырёх модуль нельзя пролистать: следующая страница открывается
только после реального действия. Подробности решений — в `CLAUDE.md`.

## Как запустить

Никакой сборки. Открыть `index.html` в браузере, либо:

```
python3 -m http.server 8777
```

## Структура

```
index.html                 витрина для сравнения
shared/module-01.js        весь контент модуля — единый источник правды
concepts/{a,b,c,d}/        четыре прототипа
source/                    исходный документ заказчика
CLAUDE.md                  принятые решения и статус работ
```

Правка текста делается только в `shared/module-01.js` — обновляются сразу все четыре варианта.
